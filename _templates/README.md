# _templates (not published)

Files from the original theme author's site (Emmanouil Antonios Platanios), kept for reference only.
Jekyll skips folders that start with `_`, so nothing here is served on antu-saha.github.io.

- `cv/index.html`: his CV page; its card layout is the template for `/cv/` and `/resume/`.
- `projects/<name>/`, `news/`: his project and news pages.
- `assets/`: his PDFs, slides, images, and the `github-stars.js` script.
- `removed_blocks/`: commented-out HTML removed from the live pages in Nov 2026.
- `Gemfile`, `Gemfile.lock`, `bin/`: unused Jekyll build files from the theme.
