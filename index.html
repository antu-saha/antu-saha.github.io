Research Interests

My research is in AI for software engineering (AI4SE), with a focus on software maintenance and evolution. I conduct empirical studies and build techniques and tools that help end users, developers, and AI coding agents report, analyze, and resolve software issues, such as bugs and feature requests. I work with issue reports, developer discussions, source code, and the user interfaces of mobile apps, using LLMs and program analysis.

Vision. AI coding agents can now fix bugs from issue reports, but users still write free-text reports and wait while developers ask questions, reproduce the problem, and fix it. My long-term goal is vibe bug resolution: a user describes a problem in their own words to an AI agent, which asks what it needs, reproduces the problem, fixes it, and confirms the fix with the user. Developers then review the change before release.

Recent work.

  • What AI coding agents need from bug reports. We ran three agents (Codex, Claude, and Qwen) on about 50 real Android UI bugs from over 20 apps. We varied the bug report content in more than a dozen ways, for over 7,500 repair attempts. Steps to reproduce had positive estimated effects for all three agents. Code localization reduced the median repair cost by over 30% for both Codex and Claude. FSE'27, under review
  • How agents repair UI bugs. In a companion study of hundreds of repair attempts, agent patches passed the tests in about three-quarters of attempts. About one in seven attempts matched the developer's fix. Nearly all other test-passing patches were valid alternative fixes, and very few overfit the tests. FSE'27, under review
  • Better bug reports. BugScribe grounds an LLM in the app's execution data to improve user-written bug reports. It improved the quality of the steps to reproduce by 44.2%–84.7% and raised an LLM agent's bug reproduction rate by 28.1%–57.7%. MSR'27, under reviewarXivArtifact
  • Issue resolution in practice. We analyzed 356 Firefox issue reports and found 47 recurring resolution patterns. ICSE'25arXivDataset

My work includes six peer-reviewed papers (ICSE, ISSTA, ICSME, MSR, and ICPC) and eight papers under review. Our ICSE'25 and ISSTA'24 artifacts received the Available, Functional, and Reusable badges. See the Research and Publications pages for details.
